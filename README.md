# 🏁 RaceDay — Event Management System

A full-stack event management platform for the South African road running, walking, and cycling community. 

This repository contains the complete solution for the three-part Portfolio of Evidence (PoE). Part 1 focused on planning, Part 2 on the RESTful API, and Part 3 on the MVC frontend, Azure Blob Storage, and Docker containerization.

---

## ✅ CI/CD Build Status

![RaceDay CI](https://github.com/YOUR-GITHUB-USERNAME/Race-Day/actions/workflows/dotnet.yml/badge.svg)

Every push triggers the GitHub Actions workflow that:
- Restores NuGet packages
- Builds the entire solution in Release mode
- Runs all xUnit tests
- Uploads the `.trx` test results as an artifact
